Platform / Roadmap

From drafts in Word
to a graph Harvey owns.

Four phases, each gating the next: capture work at creation, make captured work searchable and reviewable, give clients a persistent home for it, then compound it into the model itself. Click a phase to see the concept screens.

Phase 1 · Build first

Workspace Canvas + Provenance + Capture

Draft Editor evolves into a canvas where every claim carries a live citation, every artifact auto-tags client · matter · type · position, and work auto-persists to Vault — capture-at-creation, not a retrofit.

Metric: capture rate · % artifacts with ≥1 live citation View concept → Phase 2 · Then

Cross-Matter Search + Partner Review

Natural-language search over the firm's own captured work product, permission-scoped, plus a partner surface to trace, verify, and comment on every claim in an associate's artifact.

Metric: searches/user/wk · % drafts citing a prior artifact · partner MAU View concept → Phase 3 · Then

Persistent Client Spaces + Notifications

Shared Spaces become a durable, cross-matter client home — updates push to email/Slack/Teams with live deep-links, and clients on Harvey with multiple firms see them aggregated in one workspace.

Metric: client-space WAU · % interactions off-email · multi-firm spaces created View concept → Phase 4 · Compounding

Model Training Loop + Proactive Agents

Draft→edit deltas feed Harvey's own legal-model training, consent-governed and opt-in. Proactive agents push "here's what changed and the decisions you owe" into matter and client spaces.

Metric: model win-rate lift · proactive-digest engagement · NRR delta View concept →
